# 泌尿器科 治療方針コンセンサスノート

自分の臨床判断の「現時点での拠り所」を疾患別に文書化し、ガイドライン改訂・重要論文に合わせて月次で見直すためのリポジトリ。

## 構成

| パス | 内容 |
|---|---|
| `notes/` | 疾患別の治療方針ノート（本体） |
| `interview/` | 初版作成用の聞き取りシート（回答 → ノートへ反映） |
| `monitoring/sources.md` | 監視対象のガイドライン・学会・雑誌・検索語 |
| `monitoring/update_protocol.md` | 月次更新の手順（自動実行セッションが従う） |
| `reports/YYYY-MM.md` | 月次レポート（新着エビデンスと修正提案） |
| `CHANGELOG.md` | 方針変更の履歴 |

## 運用フロー

1. **初版作成**：聞き取り → `notes/` に「自分の方針」として記載 → ガイドラインとの乖離を `⚠ 要確認` として注記
2. **月次更新（毎月1日）**：自動セッションが新着ガイドライン・論文を検索し、
   - `reports/YYYY-MM.md` に要約
   - 該当ノートへの修正案を **Pull Request** として作成
3. **確認**：PR を読み、採用するものだけマージ（＝自分のコンセンサスとして確定）。不採用・保留は PR にコメント

## 記載ルール

- **方針**（黒字）＝自分のコンセンサス。**Claude 提案**は `> [!CAUTION]` ブロック（GitHub では赤枠、HTML 版では赤字）にリンク付きで書く。採用したら「方針」へ移し、ブロックを削除する
- HTML 版（スマホ閲覧用）は `python3 tools/build_html.py <出力パス>` で生成する

- **自分の方針**と**ガイドライン推奨**を分けて書く。乖離がある場合は理由を残す（保険適用・施設事情・エビデンス評価など）
- 根拠には出典（ガイドライン名・版、試験名、PMID/DOI）を付ける
- 日本の保険適用状況を明記する（未承認・適応外は明示）
- 変更時は各ノート末尾の「改訂履歴」と `CHANGELOG.md` を更新する

> 本ノートは個人の臨床判断の整理用であり、個々の患者への適用は最新の添付文書・ガイドラインで確認すること。
